# Ảnh màn hình đầu (hero) trang chủ

Mọi ảnh trong thư mục này đều được trình chiếu ở màn hình đầu trang chủ, mỗi ảnh 13 giây.

- Định dạng: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`
- Thứ tự: theo tên file, nên đặt tiền tố số: `01-…`, `02-…`, `03-…`
- Kích thước gợi ý: ngang khoảng 2400px, dưới ~600 KB (nén trước khi thêm)
- Ảnh hiển thị phủ kín màn hình (cắt bớt mép), nên giữ chủ thể ở giữa ảnh
- Thêm hoặc xoá file là đủ, không cần sửa code
