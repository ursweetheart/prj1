# Ảnh dự án

- `<slug>.jpg` (ví dụ `du-an-mau-01.jpg`): ảnh đại diện, hiện ở lưới "Dự án" trang chủ.
- Thư mục `<slug>/` (ví dụ `du-an-mau-01/`): ảnh hiện trong khung xem ảnh của trang `/du-an/<slug>`.
  - Thả ảnh vào là đủ, không cần sửa code.
  - Thứ tự theo tên file, nên đặt `01-…`, `02-…`, `03-…`.
  - Định dạng: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
  - Thư mục trống thì trang dự án chỉ hiện ảnh đại diện.
- Nên nén ảnh trước khi thêm: ngang khoảng 2000px, dưới ~600 KB.
